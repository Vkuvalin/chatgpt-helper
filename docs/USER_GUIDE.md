# Руководство пользователя `chatgpt-helper`

`chatgpt-helper` — расширение Manifest V3 для ChatGPT. Оно добавляет рабочую панель с шаблонами, словарём, сохранёнными фрагментами и настройками, а также позволяет анализировать и переводить выделенный текст через OpenRouter.

## 1. Что понадобится

Для работы нужны:

- браузер на базе Chromium, который умеет загружать распакованные расширения Manifest V3;
- каталог проекта `chatgpt-helper`;
- доступ к `https://chatgpt.com/` или `https://chat.openai.com/`;
- OpenRouter API key — только для анализа, перевода и проверки самого ключа.

Репозиторий не задаёт официальную матрицу поддерживаемых браузеров и версий.

Без OpenRouter работают:

- шаблоны и папки;
- сохранённые фрагменты;
- словарь и поиск по уже сохранённым терминам;
- нормализация поля ввода;
- темы, обои и настройки;
- импорт и экспорт.

OpenRouter требуется для анализа, перевода и проверки API key. При inline-поиске в уже сохранённом словаре он не используется.

## 2. Установка

Расширение загружается напрямую из исходного каталога. Сборка и `npm install` не требуются.

### Получение файлов

**Download ZIP**

1. Откройте репозиторий `Vkuvalin/chatgpt-helper` на GitHub.
2. Выберите **Code → Download ZIP**.
3. Распакуйте архив.
4. Убедитесь, что в корне находится `manifest.json`.

**Git clone**

```bash
git clone https://github.com/Vkuvalin/chatgpt-helper.git
```

### Загрузка распакованного расширения

1. Откройте страницу управления расширениями.
2. Включите режим разработчика.
3. Выберите загрузку распакованного расширения.
4. Укажите каталог `chatgpt-helper` с `manifest.json`.
5. Откройте или обновите вкладку ChatGPT.

Для Google Chrome обычно используется:

```text
chrome://extensions
```

Названия кнопок могут отличаться в разных версиях браузера.

> Ручная проверка владельца, а не контракт репозитория: расширение проверялось в Яндекс.Браузере, где страница расширений открывалась через `browser://extensions`.

### Обновление после изменения файлов

1. Нажмите **Reload** / **Обновить** у расширения.
2. Обновите открытые вкладки ChatGPT.
3. Если на странице осталась старая версия расширения, закройте вкладку и откройте новую.

## 3. Первый запуск

Расширение активируется на:

- `https://chatgpt.com/*`;
- `https://chat.openai.com/*`.

Иконка расширения на панели инструментов браузера переключает панель: открывает её на поддерживаемой странице и закрывает при повторном нажатии. Когда панель закрыта, её также открывает экранная кнопка **Открыть меню шаблонов**.

Разделы панели:

- **Шаблоны**;
- **Анализ текста**;
- **Сохранённое**;
- **Настройки**.

Шаблоны, настройки, обои, история недавних шаблонов и API key общие для профиля расширения на обоих поддерживаемых сайтах. Словарь и сохранённые фрагменты состоят из глобальных записей и связей с конкретными разговорами: глобальный поиск видит записи всего профиля, а локальный список и его порядок относятся к текущему разговору.

Для нового чата расширение создаёт временную привязку. После появления URL `/c/<conversation-id>` она автоматически становится стабильной вместе со связанными записями.

> `chatgpt.com` и `chat.openai.com` используют отдельные области данных разговоров, даже при одинаковом conversation ID.

## 4. OpenRouter

OpenRouter API key нужен для AI-функций и проверки ключа.

### Сохранение ключа

1. Откройте настройки расширения.
2. Вставьте API key.
3. Нажмите **Сохранить ключ**.
4. При необходимости нажмите **Проверить ключ**.

Ключ должен содержать от 20 до 512 символов без пробельных и управляющих символов.

После сохранения значение не отображается и не копируется обратно. Доступны действия:

- **Проверить ключ**;
- **Заменить ключ**;
- **Удалить ключ**.

Удаление ключа не удаляет шаблоны, словарь, сохранённые фрагменты или настройки.

### Хранение и конфиденциальность

Ключ хранится в отдельной IndexedDB расширения, после сохранения скрыт и не включается ни в один экспорт. Репозиторий не шифрует ключ: отдельное хранилище само по себе не является шифрованием.

При анализе или переводе выделенный текст отправляется OpenRouter. Действие **Проверить ключ** также обращается к OpenRouter. Шаблоны, настройки, словарь и сохранённые фрагменты хранятся локально в профиле браузера.

## 5. Шаблоны и папки

### Создание и редактирование

1. Откройте **Шаблоны**.
2. Нажмите **Добавить шаблон**.
3. Укажите имя, содержимое, иконку и расположение.
4. При необходимости включите Auto-send.
5. Сохраните шаблон.

Кнопка **Создать папку** позволяет создать папку в корне. Внутри папки доступны отдельные действия **Добавить шаблон в папку** и **Создать вложенную папку**. Кнопки **Редактировать шаблон** и **Редактировать папку** открывают тот же inline-редактор; одновременно открыт только один редактор, а изменения применяются после сохранения.

Ограничения:

- имя шаблона или папки не может состоять только из пробелов и содержит не более 120 символов;
- содержимое шаблона не может состоять только из пробелов и содержит не более 200 000 символов.

### Использование шаблона

Нажмите кнопку **Запустить шаблон** с иконкой воспроизведения. Наведение на имя или иконку показывает предпросмотр, но само по себе шаблон не запускает.

Расширение вставляет содержимое в поле ввода (composer) и проверяет результат. Если там уже есть текст, шаблон добавляется после него через два перевода строки и не заменяет существующее содержимое. После успешной вставки шаблон появляется в списке недавних.

При включённом Auto-send расширение пытается отправить сообщение только после проверки вставки. Если проверка или отправка не подтверждена, текст остаётся в composer, а расширение показывает ошибку.

### Папки и перемещение

Папки можно сворачивать, разворачивать и перемещать вместе со всем содержимым. Максимальная глубина — 6 уровней.

Для drag-and-drop используйте маркер **Перетащить шаблон** или **Перетащить папку**:

- верхняя и нижняя зоны карточки ставят запись до или после неё;
- центральная зона папки перемещает запись внутрь;
- **Переместить в корень** возвращает запись на верхний уровень;
- свёрнутая папка раскрывается после наведения при переносе.

Расположение также можно выбрать в редакторе. Нельзя вложить папку в саму себя или в её дочернюю папку, создать цикл либо превысить максимальную глубину.

### Удаление

Включите **Режим удаления**, затем выберите запись. Для шаблона появляется подтверждение **Удалить шаблон?**. Для папки доступны два режима:

- **Удалить только папку** — её прямые элементы поднимаются на один уровень;
- **Удалить папку и содержимое** — после дополнительного подтверждения **Безвозвратно удалить** удаляется всё поддерево.

Пользовательской Undo для этих операций нет.

### Иконки

Доступны только встроенные иконки из разрешённого списка:

```text
folder, document, code, terminal, database,
checklist, chart, globe, translate, brain,
spark, shield, bug, bookmark, rocket
```

Произвольный SVG или HTML не поддерживается.

### Недавние шаблоны

Когда панель закрыта, наведение на кнопку **Открыть меню шаблонов** показывает список **Последние запущенные шаблоны**, если эта настройка включена и история не пуста. Выбор записи в списке сразу запускает шаблон.

По умолчанию функция включена и показывает 3 шаблона. Допустимый диапазон — от 1 до 8.

## 6. Сохранённые фрагменты и словарь

### Сохранение текста

1. Выделите текст на странице ChatGPT.
2. Используйте контекстное меню **Сохранить выделенный текст** либо browser command `save-selection`.
3. Откройте раздел **Сохранённое**.

Максимальная длина — 200 000 символов.

В разделе есть режимы **Локально** и **Глобально**. Локальный список и поиск относятся к текущему разговору; глобальный поиск охватывает весь профиль и начинает показывать результаты после ввода запроса. Без поискового запроса локальные записи можно менять местами перетаскиванием.

Сохранённый текст можно скопировать. В глобальном режиме кнопка **Добавить в чат** связывает запись с текущим разговором. В меню удаления **Из чата** удаляет только локальную связь, а **Везде** — саму глобальную запись и все её связи.

Повторное сохранение одинакового нормализованного текста не создаёт ещё одну глобальную запись, а связывает существующую запись с разговором.

### Словарь

Раздел **Анализ текста** показывает словарь в режимах **Локально** и **Глобально**. Области поиска, локальная сортировка, **Добавить в чат**, **Из чата** и **Везде** работают так же, как для сохранённых фрагментов.

Для каждой записи показываются термин, перевод и определение.

### Локальный поиск по словарю

Inline-действие **Словарь** ищет только среди уже сохранённых терминов и не вызывает OpenRouter.

Оно работает для выделения до 5 000 символов и 40 строк вне редактируемых полей и интерфейса расширения. Если термин не найден, кнопка **Разобрать** запускает OpenRouter-анализ уже как отдельную AI-операцию.

## 7. Анализ и перевод

### Анализ терминов

Анализ можно запустить четырьмя способами:

- inline-действием **Анализировать текст**;
- пунктом контекстного меню **Разобрать английские термины**;
- browser command `analyze-selection`;
- кнопкой **Разобрать** рядом с отсутствующим термином в inline-словаре.

Результат показывает найденные термины, переводы и определения. Если хранилище доступно, записи добавляются в словарь и связываются с текущим разговором. Для каждой записи виден итог: **Добавлено**, **Уже сохранено**, **Есть другая версия** или **Не сохранено**. При наличии другой версии можно выбрать **Заменить сохранённую версию**; если данные успели измениться, расширение запросит повторное подтверждение.

Ограничения:

- до 20 000 символов;
- до 40 терминов;
- тайм-аут — 25 секунд;
- одна операция анализа или перевода одновременно в одной вкладке; в разных вкладках операции независимы.

При недоступном хранилище или контексте результат всё равно может быть показан с предупреждением **Не сохранено**.

### Перевод

Перевод запускается через:

- inline-действие **Перевести текст**;
- пункт контекстного меню **Перевести выделенный текст**;
- browser command `translate-selection`.

Для перевода действует тот же лимит в 20 000 символов, тайм-аут 25 секунд и общий для вкладки запрет на параллельную AI-операцию. Результат появляется в окне **Перевод** как ограниченный безопасный Markdown. Кнопка **Скопировать перевод** копирует его вручную; автоматически перевод не копируется и нигде не сохраняется.

Во время запроса видны сообщения **Анализируем выделенный текст…** или **Переводим выделенный текст…**.

### Browser commands

Manifest объявляет:

```text
analyze-selection
translate-selection
save-selection
normalize-composer
```

Сочетания клавиш по умолчанию не заданы. Их можно назначить через интерфейс браузера.

Кнопка расширения на панели инструментов открывает панель и не является отдельной browser command.

## 8. Быстрые действия

### Нормализация composer

Пункт контекстного меню **Нормализовать пустые строки** и browser command `normalize-composer`:

- сокращает последовательности лишних пустых строк;
- сохраняет caret или selection;
- допускает повторный вызов;
- не требует OpenRouter.

Поле ввода должно быть в фокусе.

### «Далее»

Быстрое действие **Далее** работает только при пустом composer: вставляет и отправляет `Далее`. При непустом composer ничего не делает.

## 9. Внешний вид

### Темы

В списке тем видны:

```text
System / Neutral
Graphite
Deep Navy
Neon Violet
Codex Gold
```

### Обои

Поддерживаются:

- PNG;
- JPG / JPEG;
- GIF;
- WebP.

Максимальный размер исходного файла — 6 MiB.

Для удаления используйте **Удалить обои**.

### Поведение панели

Можно настроить:

- **Закрывать панель после запуска шаблона**;
- **Закрывать панель при клике вне неё**;
- **Показывать последние шаблоны при наведении**;
- **Количество шаблонов** в этом списке;
- оформление словаря.

Панель изменяется по ширине за левую границу. Окна анализа и перевода изменяются за левую или правую границу; размеры сохраняются между открытиями. Кнопка **Сбросить размеры интерфейса** возвращает ширину панели и окон к значениям по умолчанию.

Для словаря доступны цвет термина (из темы или пользовательский), размеры текста **Компактный**, **Обычный** и **Крупный**, а также **Сбросить вид словаря**.

## 10. Импорт и экспорт

Настройки и пользовательские данные экспортируются отдельно. OpenRouter API key в экспорт не входит.

### Настройки

Файл:

```text
chatgpt-helper-settings.json
```

Содержит тему, обои, поведение панели и настройки списка недавних шаблонов, оформление словаря и сохранённые размеры интерфейса.

Не содержит шаблоны и папки, разговоры, словарь, сохранённые фрагменты, историю запусков, состояние свёрнутых папок и API key.

### Данные

Файл:

```text
chatgpt-helper-data.json
```

Содержит шаблоны и папки, разговоры, глобальные записи словаря и сохранённых фрагментов, а также их связи с разговорами.

Не содержит настройки и обои, API key, историю недавних шаблонов, состояние свёрнутых папок и внутренние служебные данные импорта.

> Ни JSON настроек, ни JSON данных по отдельности не являются полной резервной копией всего состояния расширения.

### Импорт

1. Выберите JSON настроек или данных.
2. Дождитесь проверки и предварительного просмотра.
3. Выберите `Merge` или `Replace`.
4. Нажмите **Применить настройки** или **Применить данные**.
5. Для `Replace` подтвердите операцию.

Предварительный просмотр показывает сводку выбранного файла и обновляется при смене режима.

Лимиты:

- JSON настроек — 10 MiB;
- JSON данных — 25 MiB.

Для настроек режим `Merge` накладывает присутствующие в файле поля на текущие настройки. `Replace` начинает с настроек по умолчанию, поэтому отсутствующие поля сбрасываются.

Для данных режим `Merge` объединяет экспортируемые данные с текущими, а `Replace` заменяет соответствующие группы данными из файла. Оба режима оставляют настройки и API key без изменений. При `Replace` история недавних шаблонов и состояние свёрнутых папок сбрасываются, поскольку они не входят в формат экспорта.

При техническом сбое импорт пытается восстановить состояние до операции. Это техническое восстановление не является пользовательской Undo после успешного импорта.

## 11. Удаление и сброс

Единой команды **Сбросить всё** нет.

Доступны отдельные операции:

- удалить API key;
- удалить обои;
- сбросить размеры;
- сбросить оформление словаря;
- удалить шаблон или папку;
- удалить запись словаря или сохранённый фрагмент только из текущего чата;
- удалить такую запись везде;
- применить импорт настроек или данных в режиме `Replace`.

`Replace` для данных не является полным сбросом: настройки и API key остаются без изменений.

Удаление расширения через браузер может удалить локальные хранилища. Перед переустановкой рекомендуется экспортировать настройки и данные.

## 12. Решение типовых проблем

| Проблема | Что проверить |
|---|---|
| Панель не появилась | Обновите расширение на странице управления и перезагрузите вкладку ChatGPT |
| Изменения исходников не видны | Нажмите **Reload** / **Обновить** у распакованного расширения и откройте новую вкладку |
| Расширение не работает | Открыт ли `chatgpt.com` или `chat.openai.com` |
| Анализ/перевод не запускается | Наличие и проверка OpenRouter API key |
| Ошибка OpenRouter | Ключ, баланс, ограничение запросов или доступность провайдера |
| Inline-действия не появились | Выделение должно находиться вне поля ввода, другого редактируемого поля и интерфейса расширения |
| Browser command не работает | Назначено ли сочетание клавиш |
| Шаблон вставился, но не отправился | Auto-send мог не подтвердить поле ввода или кнопку отправки; текст должен остаться в поле |
| Обои не применились | Формат и размер файла |
| Импорт дал неожиданный результат | Проверьте предварительный просмотр и выбранный `Merge` / `Replace` до применения |
| Данные разговора не видны на другом сайте | `chatgpt.com` и `chat.openai.com` используют отдельные области разговоров |
| После обновления ChatGPT сломалась вставка | Интерфейс ChatGPT мог измениться; обновите страницу и расширение |

---

## 13. Ограничения

1. Расширение зависит от текущего интерфейса ChatGPT.
2. AI-операции зависят от OpenRouter, модели и API key; выделенный для них текст отправляется внешнему провайдеру.
3. Данные хранятся в текущем профиле браузера, встроенной синхронизации между устройствами нет.
4. Два адреса ChatGPT используют отдельные области данных разговоров.
